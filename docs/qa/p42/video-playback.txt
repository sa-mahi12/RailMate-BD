==========================================================

The page is the published GitHub Pages build
(`https://sa-mahi12.github.io/RailMate-BD/`), reading the hosted Supabase
project `psuzlyingfmstnyfvlnj`. The video is an object that account A uploaded
through the real Storage API into the public `post-media` bucket during the

asset pretending to be user media.

Two defects were found by these measurements and fixed before the claim:
the page rebuilt the whole feed every 20 s (stopping playback mid-watch), and
GitHub Pages' `max-age=600` asset cache served the pre-fix `app.js` after a
deploy (the deploy step now stamps `?v=<commit>` onto asset URLs).

What this does and does not show
--------------------------------
* Shows: an uploaded WebM streams from Supabase Storage and plays in a normal
  browser on the public URL.
* Does not show: an Android-device playback run (no phone/emulator run of the
  new attachment UI was recorded in this packet).
* Provider links (`https://youtube.com/...`) are a different feature: they stay
  a click-to-load button (`Play youtube video`), never an auto-loaded frame.
