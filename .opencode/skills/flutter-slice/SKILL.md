# Small Flutter UI or feature slice

Implement only the packet-defined widget/route/service. Prefer simple StatefulWidget or minimal existing state solution; do not install heavyweight packages without need. Have loading, empty, error, success, retry and disposed/return states; validate phone sizes using actual device. No new feature outside matrix. A passing mocked widget test is UNIT-MOCK, not device proof.
