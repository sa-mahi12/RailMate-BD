# User-controlled OpenRouter key handling

Never ship API key. Save user key in Android secure storage with remove/logout semantics; do not send it to Supabase or logs. One explicit Improve Wording action sends draft text only to verified OpenRouter origin. User approves text change; no paid fallback or developer key. Test no-key and provider failure without blocking booking.
